## 반드시 지킬 것

- **{{WORKTREE}} 안에서만 작업한다.** 이 폴더는 너만 쓰는 git worktree 이고
  이미 브랜치 {{BRANCH}} 가 체크아웃돼 있다. 본체({{ROOT}})나 다른 패널의
  worktree 를 건드리면 그쪽 작업이 통째로 뒤섞인다.
- `git checkout` 으로 브랜치를 갈아 끼우지 마라. 이미 맞는 브랜치다.
- `git add -A` 를 쓰지 마라. 바꾼 경로를 하나씩 지정한다.
- 남의 미커밋 변경에 손대지 마라. 시작 전 `git status` 로 확인한다.
- 이 단원과 직접 관련된 파일만 고친다. 광범위 리팩터링 금지.
- 조문 번호·기한·세율·금액은 근거가 있을 때만 적는다. 확인 못 하면 그
  항목을 빼고 `<!-- 확인 필요: … -->` 를 남겨라. SPEC.md §4 를 읽어라.
- 끝내기 전에 `npm run build` 를 직접 돌려 통과시켜라.

## ⚠ 산출물 경로를 착각하지 마라

산출물은 **위에 적힌 절대경로 그대로** 만들어라. `cd` 한 뒤 `.pipeline/...`
같은 **상대경로로 만들면 worktree 안쪽에 생기고, 그것은 아무도 안 본다.**
2026-08-27 에 열두 과제가 이렇게 엉뚱한 곳에 써서 다음 차수가 "파일이 없다"
며 FAIL 을 냈다. 억울하게 되돌림 횟수만 탔다.

만든 뒤 `ls -la <절대경로>` 로 **실제로 그 자리에 생겼는지 확인하라.**
