# 제37회 공인중개사 시험 법령 학습 기준

이 웹페이지의 제37회 시험용 본문은 다음 프로젝트 학습 기준을 적용한다.

- **2026년 5월 31일까지 공포·개정된 법령**은 제37회 시험 정답용 본문에 적용한다.
- **2026년 6월 1일 이후 공포·개정된 법령**은 제37회 정답 본문에 적용하지 않고, 과목별 `개정법 적용·차이 보기`에서 개정 전/후와 시험 처리 차이를 별도로 표시한다.
- 적용 여부의 판정축은 **시행일이 아니라 공포·개정일**이다. 따라서 2026년 5월 31일까지 개정되었다면 시행일이 6월 이후여도 이 프로젝트의 제37회 학습기준에는 포함한다.
- 2025년에 공포·개정된 규정은 당연히 컷오프 이전이므로 제37회 본문에 포함한다.
- 2026년 6월 1일 이후 개정분은 **제38회 대비 비교자료**로 분리한다.
- 법령 개정 사실과 개정 전/후 근거는 국가법령정보센터 링크로 연결한다.

이 기준은 박 목사님이 지정한 사이트의 학습 운영 기준이다. 전 과목에 동일하게 적용하며, 향후 프로젝트 기준을 다시 변경할 경우 전 과목·법령 팝업·자동검증을 함께 갱신한다.
