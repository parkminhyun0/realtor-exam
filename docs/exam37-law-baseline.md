# 제37회 공인중개사 시험 법령 학습 기준

이 웹페이지의 제37회 시험용 본문은 다음 기준을 적용한다.

- 2026년에 공포·개정된 법령은 시험 정답용 본문에 직접 반영하지 않고 개정 전 규정을 우선한다.
- 2026년 개정법은 과목별 `2026 개정법 차이 보기`에서 개정 전/후와 시험 처리 차이를 별도로 표시한다.
- `올해 개정법`은 2026년에 공포·개정된 규정을 뜻한다.
- 2025년에 공포되어 2026년에 시행된 규정은 이 원칙만으로 자동 제외하지 않는다.
- 법령 개정 사실과 개정 전/후 근거는 국가법령정보센터 링크로 연결한다.

이 기준은 사이트의 학습 운영 기준이다. 공식 시행계획·시험 공고에서 별도의 법령 적용 기준이 확인되는 경우 그 공식 기준을 우선하여 다시 조정한다.
